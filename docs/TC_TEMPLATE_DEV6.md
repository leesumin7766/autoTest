# dev6 TC 템플릿 전체 생성과 실행 선택

## 정책

사용자 요청에 따라 로그인 27개, 주요기능 9개, 부가기능 9개, CRUD 16개를 기능별로 모두 생성한다. 원본 메뉴의 기능구분을 유지한다. 제품당 공통 39개·제품설명서 7개·사용자취급설명서 22개도 유지한다. 생성 단계에서 비적용 후보를 삭제하거나 결과 N/A를 채우지 않는다.

예시 Excel의 CRUD는 15개다. 요청된 16개 구성을 위해 마지막 항목에 '삭제 확인에서 취소하면 원본 데이터가 유지되는지' 검증을 추가했다. 주요/부가의 9개와 로그인 27개는 기존 기준을 계승했다. 로그인은 기존 정책대로 정상 로그인 시험을 먼저 표시한다.

`tc-templates/menu-tc-v3.json`에 규칙·품질 분류·시나리오·입력·기대 결과·결함 예시·요구 동작을 저장한다. 이전 은행 파일은 변경하지 않는다. `templateOriginal`로 원본 규칙을 각 TC에 보존하고 제품의 기능명·경로를 본문과 결함 예시에 연결한다. 명시적 등록/조회/수정/삭제/업로드 기능의 기본 수행 시험은 동작별 절차·기대 결과를 적용한다. 임의 선택자·계정값·정답 수치는 만들지 않는다.

## 원본과 실행 정보

- TestCase 기존 16열, 순서, 품질 분류, 결과 빈칸, P/F/N/A 선택 목록 유지.
- 기존 실행 정보 12열 유지. 뒤에 TC 내용 버전, 템플릿 버전, 자동화 방식, 실행 선택 상태, 선택 검토 사유, 구조화 실행 명세, 대기·재시도 정책, 정리·복구를 추가한다.
- 생성 상태 PENDING_LLM은 아직 모델 판정을 하지 않았다는 뜻이다. 4개 TC 산출물 전체에 모델 판정이 완료됐다는 뜻이 아니다.
- 실행 명세는 데이터·정답 근거·화면 요소가 연결되기 전에는 NEEDS_CONTEXT/UNRESOLVED다. 메뉴트리만으로 완성된 자동 실행 스크립트라고 표시하지 않는다.
- 결함 예시는 실제 결함이 아니며, 원본 TC의 결과는 실행 선택으로 수정하지 않는다.

## 실행 선택

브라우저 실행 직전에 AI가 전달받은 TC의 실행 선택을 확인한다. 코드가 명확한 단일 동작명과 규칙의 요구 동작의 불일치를 후보로 만들고 Qwen 8B가 확인한다. 예를 들어 삭제 전용 기능에 대한 등록·수정·조회 시험은 제외 후보가 된다. '추가/수정/삭제' 같은 복합 기능은 단일 삭제 기능으로 해석하지 않는다.

실행 제외 확정 조건은 코드상의 동작 불일치, 모델 NOT_APPLICABLE, 신뢰도 0.90 이상, 현재 기능명과 정확히 일치하는 근거 인용이다. 불확실·잘못된 인용·응답 오류는 NEEDS_CONTEXT로 남긴다. 같은 제품 전체에 등록 기능이 없다고 추론하지 않으며 현재 기능 범위만 판단한다.

확인된 항목은 EXCLUDED로 브라우저를 열지 않는다. 결과는 null, 판정은 검토 필요로 남겨 자동 N/A 확정과 구분한다. 원본 TC와 모델·인용·신뢰도·사유·무동작 계획을 보존한다. UI는 실행 제외 수와 선택 진행 단계를 별도로 표시한다.

저장 해시 등 내부 상태를 확인해야 하는 로그인 시험은 추가 증거가 필요하다고 표시한다. 화면만 보고 P를 판정하지 않는다. 생성 대상에서 제외하는 것은 아니다. 범용 비적용 자동 판정과 임의 제품 기능의 실행 명세 완성은 아직 범위 밖이다.

## 검증 결과

- Java 10건 통과: 생성기 6, 인증 정책 3, API/worker 통합 1. 격리 DB autotest_test 사용.
- Python 26건 통과: 기존 실행·증거·프로필 22 + 새 실행 선택 4. 낮은 신뢰도·잘못된 인용·모델 오류·복합 기능·원본 보존·브라우저 미수행을 확인.
- 실제 Qwen 8B 검증: 4번째 제품의 DEK 삭제 아래 CRUD 등록 시험 TC-015-006을 신뢰도 0.95로 실행 제외. 원본 TC 유지, 결과 null, 브라우저 조작 0건. 원응답은 execution-selection-example.json에 포함.
- 4개 시트의 기능 435개를 모두 반영, TC 4,466건. 로그인별 27개·CRUD별 16개를 검사. Excel 결과 셀 빈칸·수식 미포함·TC ID 중복 없음·기능 누락 없음·헤더 유지·JSON과 Excel 일치를 검증.
- 프런트엔드 TypeScript/Vite 빌드 통과. 이번 검증은 4,466건의 실제 제품 기능 시험을 실행했다는 뜻이 아니다.

## 재현

`gradlew.bat :test-management-service:generateMenuTcSamples -PtcSampleOutput=<출력 절대 경로>`

운영 API와 동일한 MenuTcGenerator/MenuTcWorkbook으로 4개 Excel과 JSON, SHA-256 생성 보고서를 출력한다. 브라우저 실행과 독립적으로 재현할 수 있다. 코드·문서·테스트는 dev6에서 관리하며 이 작업에서 개발 서버 배포는 수행하지 않았다.
