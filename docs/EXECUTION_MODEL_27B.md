# 시험 계획 모델 변경 — 2026-10-27

사용자 요청 모델은 `qwen3.8:27b`다. Compose 기본값, 일반 계획·실행 선택·최초 URL 복구·정상 로그인 계획의 기본값을 동일하게 변경한다. 제품 설명/과거 TC 생성용 LLM 설정은 별개로 유지한다. 실제 실행 모델은 `EXECUTION_QWEN_MODEL` 환경변수와 capabilities의 model 필드로 확인한다.

Ollama 공식 모델: https://ollama.com/library/qwen3.8:27b

컨테이너 Ollama 0.40.0에 모델 다운로드와 등록을 완료했다. 첫 응답 검증은 로딩 180초 한도를 넘겼고 이후 Docker API도 응답 오류를 보였다. 당시 Docker 메모리 한도는 약 16GB, 호스트 RAM은 약 32GB였으며 별도 NVIDIA GPU는 확인되지 않았다. 설치와 실제 추론 성공은 구분한다. 메모리 조정·재시작은 다른 WSL 프로그램에도 영향을 주므로 사용자 승인을 요청한 상태다. 런타임 검증과 서버 반영 결과는 확인 후 이 문서를 갱신한다.

인증 시작 상태와 팝업 관찰 수정은 [별도 변경](EXECUTION_SESSION_STATE.md)이다. 모델 크기 변경만으로 인증 TC의 사전조건·비밀번호 입력 지원 문제가 해결됐다고 설명하지 않는다.
