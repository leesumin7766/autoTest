# 메뉴트리·인증 TC 보완 (2026-10-23)

이번 범위는 메뉴트리 작성 방식의 재사용과 로그인 TC 생성이다. 시험 실행·판정 구조의 개편은 포함하지 않는다.

## 메뉴트리

- 외부 LLM용 공통 규칙을 `self-llm-v3`으로 갱신했다. 제품 범위 확정, 실제 웹 구조·관찰 순서, 독립 조작별 마지막 기능 행, 문서 기능 역대조, 미배치 기능 보존, 한국어 설명과 예시를 고정한다.
- 제품별 고정 자료에 인증 근거 요약과 대상 제품 한정 지침을 포함한다. 문서·화면 안의 명령은 데이터로 취급한다.
- 같은 경로·기능명·설명의 중복 외부 응답은 가져오기에서 거부한다. 원문은 기존처럼 서버에서 복원한다.
- 가져오기·편집·승인 시 문서 구간 참조 현황을 계산하고 UI에서 미참조 원문을 확인할 수 있게 했다. 이것은 기능별 의미적 누락 검증이 아니다. 표지·타 제품 구간도 미참조일 수 있으므로 사용자 검토가 필요하다.
- 외부 모델에 자동 API 호출하는 변경은 아니다. 공통 지침 등록 → 제품별 프롬프트 → JSON 가져오기 흐름을 유지한다. 이전에 복사한 v2 요청은 새 v3 프롬프트로 다시 생성해야 한다.

## 인증 TC

- `menu-tc-v2` 생성기는 기존 v1 시험 기준 은행을 재사용한다. 생성 방식 버전은 입력 해시에 포함해 과거 초안을 잘못 재사용하지 않는다.
- 승인 메뉴의 로그인 행, 인증 문서, 로그인 전 수집 화면 또는 완료한 인증 크롤링으로 로그인 필요성을 확인한다. 사이드바에 로그인 행이 없어도 인증 그룹을 추가한다.
- 로그인 그룹을 앞에 배치하고 정상 로그인 `LOGIN-04`를 첫 TC로 배치한다. 기존 로그인 기능이 있으면 자동 추가 행을 중복 생성하지 않는다. 로그아웃은 기본 분류에서 로그인으로 취급하지 않는다.
- `LOGIN-17/18`에 문서 기반 잠금 횟수와 근거·시험 절차를 반영한다. 5회를 기본값으로 만들지 않는다. 정책이 없거나 여러 값이면 확인 필요로 남긴다. 전용 계정과 해제·복구 절차를 필수 시험 정보로 기재한다.
- 정책 추출은 한국어 비밀번호·로그인·인증/횟수/잠금 문구에 대한 규칙이다. 복잡한 조건·표·시간·영문 정책의 완전한 해석을 보장하지 않는다. 모든 TC는 검토가 필요한 초안이며 잠금 시간을 추정하지 않는다.
- 업로드 메뉴트리에 인증 행과 수집·문서 근거가 모두 없다면 인증 기능을 추정하지 않는다.

## 수집

- FORM_AUTO에서 아이디·비밀번호 입력 전에 로그인 화면을 별도 캡처한다. 입력 영역은 마스킹하고 `PRE_AUTH`로 구분하며 인증 화면의 링크를 탐색하지 않는다.
- 새 수집에만 적용된다. 과거 결과는 다시 쓰지 않는다. 로그인 화면도 저장 화면 수·페이지 한도에 포함된다.
- 연결·로그인 확인용 probe는 기존처럼 화면 수집을 하지 않는다.

## 검증

- 3/5/10회 정책, 정책 없음·충돌, 로그인 누락 자동 추가·중복 방지, 로그아웃 분리와 정상 로그인 우선 순서 단위 검증.
- 메뉴트리 외부 응답 원문 복원·중복 거부·구간 참조 집계 검증.
- 테스트 전용 DB의 업로드 → 선택 → 생성 → 저장 → Excel API 검증에 인증 누락 보완 경로 추가.
- 합성 웹사이트에서 실제 Playwright 로그인 전 수집·인증서 예외·재개 검증. 실제 대상 계정에 비밀번호 실패·잠금 시험은 수행하지 않는다.

기존 검토 완료 메뉴트리와 과거 TC·시험 결과는 변경하지 않는다. 새 TC 생성 시 보완을 적용한다.
