# 미완료 메뉴 선택 재수집

실패 목록은 기본 접힘 상태다. 펼치면 240px 높이 안에서 메뉴와 짧은 사유를 확인하고, 행을 펼치면 오류 코드와 단계를 확인한다. 상위 경로 체크 시 목록에 있는 하위 항목도 체크되며 해제도 함께 적용한다.

- 선택 화면만(SELF): 체크한 화면만 새 캡처를 저장한다.
- 선택 화면 + 하위 메뉴(SUBTREE, 기본값): 선택 경로와 그 하위의 관찰된 메뉴를 탐색·캡처한다.

접속·로그인은 기존 설정으로 수행한다. 선택 화면에 도달하는 데 필요한 상위 메뉴는 이동에 사용하지만 저장 범위에는 포함하지 않는다. 다른 분기는 탐색하지 않는다. 메뉴 ID와 경로는 원본 작업의 실패 목록에서 서버가 가져오며 클라이언트가 임의 URL·경로를 지정할 수 없다.

새 작업에 기존 캡처를 복사하며 원본 작업은 변경하지 않는다. 성공한 항목은 새 실패 목록에서 빠지고 선택하지 않은 실패는 보존된다. 제한·시간 초과로 수행하지 못한 선택 항목도 미완료로 남는다. 이전 결과에 메뉴 ID나 경로가 없는 항목은 기존 전체 이어서 수집을 사용한다.

원격 실행기는 crawl-targeted-retry-v1 지원 버전이 필요하다. 구버전 실행기에 선택 범위를 전달해 전체 수집이 실행되는 일이 없도록 서버에서 거부한다. 다운로드 ZIP에 retry.js가 포함된다.

검증: 실제 Chromium의 SELF/SUBTREE 범위·관련 없는 분기 제외·기존 캡처 보존·기존 전체 resume, API 소유권·임의 대상 거부·실행기 버전 검사, UI 접힘·부모/자식 체크·해제·범위 선택.
