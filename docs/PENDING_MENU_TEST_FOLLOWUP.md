# 현재 테스트 종료 후 반영할 사항

2026-10-21 사용자 요청. 진행 중인 테스트를 중단·재시작하지 않고 종료 후 반영한다.

- 수집 결과 숫자 이름을 `저장된 캡처 수`, `중복 제외 확인된 화면 상태 수`, `실패한 이동 건수`로 구분한다.
- 실패한 이동의 메뉴 경로·실패 단계·실패 사유를 수집 결과 화면에서 펼쳐 볼 수 있게 한다. 원본은 `crawlResult.skipped`다.
- 중복 캡처 수 및 집계 기준을 안내한다. 이동 실패는 캡처 수에서 빼는 숫자가 아니다.
- 확인한 실행 d3f69e65-7b18-4194-a914-ffc49a6f1c71: 캡처 33개, 고유 확인 상태 30개, 이동 실패 5건, 로딩 미완료·변화 미확인 0건. 중복 화면 상태 3건.

통합 메뉴 생성의 376은 해당 입력을 모델 예산에 맞게 나눈 분석 구간 수이며 메뉴·기능 결과 행 수가 아니다. 전체 구간 처리가 끝난 뒤 병합·최종 검증·초안 저장을 거친다. 오류나 시간 초과로 먼저 종료될 수 있고, 모든 구간을 처리해도 검증 실패 구간이 있으면 부분 초안이다.
