# 프런트엔드 작업 공간

기존 API와 기능 패널을 유지하면서 자료 등록, 화면 수집, 메뉴트리를 좌측 탐색으로 분리했다. 처음 방문한 패널은 이후 숨김 상태로 유지하므로 화면을 전환해도 입력값·편집 내용과 진행 중인 작업의 상태 조회가 유지된다. 새 문서 세트 또는 세트·회원 변경 시에는 기존과 같이 패널을 초기화한다.

- 자료 등록: 세 문서 개별 선택, 개별·일괄 업로드, 누락 문서 안내, 실패·차단 문서 교체, 추출 결과·저장 경로, 세트 조회·초기화.
- 하단 처리 결과: 업로드·AI 전달 상태, Jev 검증 대기·진행·차단·경고·완료, 전달 복구·재시도, 상세 진단.
- 화면 수집: 접속·로그인 검사, 접속 설정 저장, 고급 설정, 로컬·원격 실행, 실행기 등록·설정 다운로드·해제, 수집·중단, 수집 메뉴·화면·근거 확인.
- 메뉴트리: 자동·외부 LLM 작성, 수집·작업 선택, 이력, 진행·중단·진단, 메뉴 구조, 기능 편집·분리·포함 여부·배치, 원문·캡처 근거, 초안 저장·편집 취소·승인, 초안·승인 Excel, 프롬프트·JSON 가져오기.

문서 카드의 초록 테두리는 정상 텍스트 추출을 뜻한다. Jev 진행 중에는 주황 테두리와 로딩 문구를 표시하고, 검증 결과는 별도 상태 배지·진단으로 구분한다. 업로드나 검증을 시뮬레이션하지 않고 서버 응답을 사용한다.

Inter 13px, JetBrains Mono, 36px 이상 버튼, 데스크톱 280px 좌측 탐색을 사용한다. 폰트는 외부 CDN 없이 번들로 제공한다. Radix 기반 탭은 shadcn/ui 방식으로 조합하며 키보드 탐색과 탭 접근성을 제공한다. 세부 화면은 기존 CSS를 보존하고 `frontend/src/workspace.css`에서 새 작업 공간에 맞게 조정한다.

## 확인

`frontend`에서 `npm run build`로 타입 검사와 프로덕션 빌드를 수행한다.

Vite를 `npm run dev -- --host 127.0.0.1 --port 4173 --strictPort`로 시작한 뒤 저장소 루트에서 `node scripts/verify-frontend.cjs`를 실행한다. 다른 주소는 `FRONTEND_QA_URL`로 지정한다. 기존 `crawler-service`의 Playwright와 설치된 Chromium을 사용한다.

브라우저 검사는 API 모의 응답으로 수행하며 실제 문서·LLM·제품 사이트·수집기는 호출하지 않는다. 상태 유지, 검증 상태·복구, 문서 교체, 연결·수집, 메뉴트리 편집·분리·제외·저장·승인·근거·외부 응답·다운로드, 부분 초안 승인 차단과 모바일 가로 넘침을 확인한다. 화면 캡처는 `output/frontend-ui/`에 저장한다. 실제 백엔드 연동 검증과는 구분한다.
