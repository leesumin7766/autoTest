# NeoFlow Server 개선 및 재검증 (2026-10-20)

## 반영한 수정

- 언어·테마·사이드바 환경 전환은 관찰만 하고 자동 클릭에서 제외.
- 인증 직후 localStorage/sessionStorage를 메모리에 보관해 매 탐색 재현 시 복원.
- DOM 위치 대신 현재 메뉴 경로·종류·링크를 재관찰해 유일한 메뉴만 클릭. 같은 URL의 다른 메뉴는 합치지 않음.
- 페이지네이션은 메뉴 탐색에서 제외하고 화면 요소 목록으로 보존.
- Java→AI 및 Java→로컬 크롤러 요청에 HTTP/1.1 명시.
- 생성 서비스 연결 실패·시간 초과·중단을 구분. 콜백 오류는 안전한 HTTP 상태·오류 코드로만 진단.
- 수집에 실패·미확인·한도 도달이 있으면 INCOMPLETE 및 화면 경고. 통합 생성의 고정 입력에도 경고 유지.
- 모델 입력 예산에 맞게 문서 구간을 재분할. 원문 ID·인용문과 겹침 구간을 보존하며 텍스트를 생략하지 않음.
