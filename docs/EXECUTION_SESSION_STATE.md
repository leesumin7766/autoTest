## 수정

- LOGIN-01/03/04/05/06/15/17/18/21은 사전 자동 로그인을 하지 않는 새 브라우저 컨텍스트를 사용한다. 로그인 폼이 실제 보이지 않으면 인증 시도 없이 중지한다. 새 비로그인 세션으로 준비하므로 이미 로그인된 대시보드에서 불필요한 로그아웃 메뉴를 탐색하지 않는다.
- 로그아웃 TC와 일반 업무 TC는 기존 저장 계정 사전 로그인 경로를 유지한다. 로그인 폼이 관찰되면 이전 AUTHENTICATED_BY_SETUP 상태를 해제한다. Qwen에는 실제 인증 상태와 TC 시작 상태를 함께 전달한다.
- 열린 대화상자·활성 메뉴가 있으면 그 영역의 본문·조작 요소를 우선한다. 배경·가려진·비활성 요소를 조작 후보에서 제외한다. 일반 화면에 상시 존재하는 role=menu는 열린 팝업으로 가정하지 않는다.
- 모델 계획은 한 번에 한 조작만 허용하고 다음 관찰 후 후속 조작을 계획한다. EXECUTE에서 확인 조건 작성을 강요하지 않는다.
- 클릭 오류를 가려짐·요소 교체·대기 초과로 구분한다. 원문 예외나 비밀정보는 공개하지 않는다.
- 전용 비밀번호 입력/변경, 잠금·복구, 역할별 계정, 복수 세션, 세션 만료 시험이 연결되지 않은 인증 TC는 브라우저·Qwen 호출 전에 구체적인 준비 필요 사유를 반환한다. 이는 제품 F나 N/A 판정이 아니며 자동 시험 지원이 완성됐다는 뜻도 아니다.
