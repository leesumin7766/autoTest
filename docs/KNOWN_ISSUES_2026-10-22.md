`TestExecutionWorker`의 Java HttpClient는 기본 HTTP/2 협상을 사용했고, Uvicorn은 이 h2c 업그레이드를 처리하지 못했다. 다른 기존 AI 호출 코드에는 HTTP/1.1 지정이 있었지만 새 실행 워커와 준비 상태 검사에는 빠져 있었다. 같은 비밀정보 없는 64 KiB POST를 실제 AI 서버에 보낸 비교에서 HTTP/2 협상은 400, HTTP/1.1은 정상 요청 검증 단계의 422를 반환했다. 비교 요청은 의도적으로 실행 입력을 생략했으므로 422가 정상 대조군이며 제품 시험을 실행하지 않았다.

수정:

- 실행 워커·준비 검사 모두 HTTP/1.1 명시.
- AI 요청 거부/인증 실패/API 누락/사용 중/타임아웃/연결 실패 분류. HTTP 오류 응답은 서비스명·상태 코드만 저장하고 응답 본문이나 자격 증명은 저장하지 않음.

- 회귀 서버가 Upgrade 헤더를 거절하도록 변경. AI 422를 요청 거부로 보존하는 테스트 추가.

검증:
