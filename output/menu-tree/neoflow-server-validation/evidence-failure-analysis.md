## 프로그램의 판단

검증은 행에서 인용한 sourceId 중 menuKey가 있는 화면 근거만 모아 allowed_keys를 만든다. 생성된 matchedMenuKeys가 allowed_keys의 부분집합이어야 한다.

이 행은 매뉴얼만 인용했으므로 allowed_keys는 빈 집합이다. matchedMenuKeys에는 실제 메뉴 키가 하나 있으므로 부분집합 검사가 실패한다. 기능 설명의 의미가 틀렸다는 판정이 아니다. 다만 해당 기능과 그 메뉴가 의미적으로 완전히 일치한다는 합격 판정도 아니다.

## 통제 비교

기능명·상위 분류·설명·위치·메뉴 키를 바꾸지 않고, 모델에 이미 제공됐던 같은 메뉴의 정확한 근거 참조 하나만 추가했다. 같은 validate_rows 검증이 PASSED로 바뀌었다. 제품 데이터와 승인 결과는 수정하지 않았다.

## 오류가 가려진 이유

재시도 코드가 MENU_MATCH_EVIDENCE_INVALID 등 여러 원인을 MENU_EVIDENCE_INVALID로 치환한다. 재시도 지시도 구체적인 누락 메뉴 근거를 안내하지 않는다. 최초 응답 및 실패 행을 보존하지 않고 전체 작업을 종료해, 최종 DB에는 총괄 오류와 고정 입력만 남았다.

## 수정 방향

- 생성 스키마·지시에서 matchedMenuKeys에 있는 메뉴마다 해당 메뉴 근거 인용을 함께 요구한다.
- 실패 행·필드·실제 거부 코드와 원래 모델 응답을 접근 통제된 진단 자료로 보존한다. 일반 로그에 문서 본문을 기록하지 않는다.
- 재시도에 정확한 검증 오류와 누락된 메뉴 근거 ID를 전달한다.
- 유효 구간은 저장하고 실패 구간만 재시도한다. 연결을 증명하지 못한 행은 연결을 해제한 문서 전용 초안으로 별도 검토할 수 있게 한다.
